# سجل العميل: وصول أسرع للمعلومة وتسجيل أسهل

الهدف: يفتح الموظف صفحة العميل فيلاقي المعلومة المهمة في ثانية، ويقدر يسجّل تذكرة أو حجز فندق أو دفعة — ويرفق ملف التذكرة (PDF أو صورة) — من نفس الشاشة بضغطة واحدة.

## 1. رأس الصفحة (ملخص فوري)
- سطر واحد فيه: اسم العميل، الجوال، المدينة، ومصدره.
- أزرار تواصل سريعة: واتساب، اتصال، بريد (موجودة — تتنقل لأعلى الشاشة).
- أربع بطاقات أرقام فقط: إجمالي الإنفاق، المحصّل، المستحق، عدد الحجوزات.
- شريط "تنبيهات": مبلغ مستحق قريب، سفر خلال 7 أيام، تذكرة لسه "قيد الإصدار" — كل تنبيه يوصّل لمكانه.

## 2. تبويبات بدل التمرير الطويل
بدل عرض كل الجداول تحت بعض:
- **نظرة عامة**: التنبيهات + آخر النشاط (خط زمني مختصر).
- **الحجوزات**
- **التذاكر**
- **الفنادق**
- **التحصيل**
- **المرفقات**
كل تبويب يعرض عدده بين قوسين، ويفتح مباشرة على المحتوى بدون بحث.

## 3. تسجيل سريع من نفس الصفحة
زر واحد أعلى السجل "إضافة" يفتح قائمة: تذكرة طيران، حجز فندق، دفعة، ملاحظة.
- **تذكرة**: الحجز، المسافر، شركة الطيران، رقم الرحلة، خط السير، تاريخ المغادرة/العودة، PNR، الدرجة، السعر، الحالة + رفع ملف التذكرة.
- **فندق**: الحجز، الفندق، المدينة، نوع الغرفة، نظام الإقامة، الدخول/المغادرة، الغرف/النزلاء، رقم التأكيد، السعر + رفع التأكيد.
- **دفعة**: كما هي حالياً + رفع صورة الإيصال.
- كل نافذة تحفظ مباشرة وتُظهر رسالة نجاح، والصف الجديد يظهر فوراً في تبويبه.

## 4. المرفقات (PDF / صور)
- رفع بالسحب والإفلات أو اختيار ملف، مع إمكانية إرفاق أكثر من ملف.
- كل مرفق يظهر كبطاقة صغيرة: أيقونة PDF أو معاينة الصورة، اسم الملف، حجمه، تاريخ الرفع، ومن رفعه.
- ضغطة على المرفق تفتحه في تبويب جديد (صورة تُعرض، PDF يُفتح بالعارض).
- زر حذف على كل مرفق.
- تبويب "المرفقات" يجمع كل ملفات العميل في مكان واحد مع فلتر: تذاكر / فنادق / إيصالات / أخرى.

## 5. تفاصيل تقنية
- أنواع جديدة في `src/lib/crm-data.tsx`: `Attachment` { id, customerId, kind: ticket|hotel|payment|other, refId?, name, mime, size, dataUrl, uploadedAt, uploadedBy } مع `addAttachment` و`removeAttachment` في المزوّد.
- المرفقات تُخزَّن كـ data URL في ذاكرة الجلسة (نفس أسلوب صور الباقات) — تختفي بتحديث الصفحة حتى مرحلة الحفظ الدائم. حد أقصى مقترح 5MB للملف مع رسالة تنبيه عند التجاوز.
- مكوّن `FileDrop` قابل لإعادة الاستخدام (سحب/إفلات + اختيار) في `src/components/crm/FileDrop.tsx` يدعم `application/pdf` و`image/*`.
- التبويبات عبر `@/components/ui/tabs` الموجود؛ لا تغيير في المنطق الحالي للحجوزات والمدفوعات.
- إعادة تنظيم `src/routes/customers.$customerId.tsx` إلى مكوّنات فرعية داخل نفس الملف للحفاظ على قابلية القراءة.
- الصلاحيات كما هي: إضافة تذكرة/فندق/دفعة ورفع مرفق تتطلب `bookings.edit`.
